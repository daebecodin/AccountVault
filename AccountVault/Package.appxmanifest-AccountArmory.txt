Apply these changes to the Package.appxmanifest already in your Visual Studio
project. The original manifest was not included in the supplied source bundle,
so it is intentionally not replaced with a guessed package identity.

Set the package properties display name:

  <Properties>
    <DisplayName>Account Armory</DisplayName>
  </Properties>

Set the application visual display name:

  <uap:VisualElements
      DisplayName="Account Armory"
      ... />

Keep these values unchanged:

- <Identity Name="...">
- Executable="..."
- EntryPoint="..."

Those are deployment/runtime identifiers. They do not need to match the name
shown to the user.
